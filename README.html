Sport-Coach System

Persönliches Coaching mit Claude Code — Dokumentation & Bedienungsanleitung

Was ist das?

Dieser Ordner ist dein persönliches Sport-Coaching-System, das mit Claude Code zusammenarbeitet. Claude kennt dein vollständiges Athletenprofil, deine Verletzungshistorie, deine Ziele und deinen Kalender — und agiert als strenger, wissenschaftlich fundierter Coach.

Das System ist kein App-Ersatz, sondern ein intelligenter Layer über deinen echten Daten: Garmin-Aufzeichnungen, Gym-Notizen, Gewichtsverlauf und Kalender fließen zusammen in strukturierte Auswertungen, Pläne und Entscheidungen.

Claude Code öffnen: Terminal → in diesen Ordner navigieren → claude eingeben. Alle Coaching-Funktionen laufen dann direkt im Chat.

Was kann Claude?

📅

Trainingsplanung

Erstellt 10-Tage-Pläne mit Kalenderabgleich. Trägt Einheiten automatisch in Google Calendar ein.

Garmin Sync

Das Script garmin_sync.py verbindet sich mit Garmin Connect und lädt neue Aktivitäten automatisch in den richtigen Unterordner.

Einmalige Einrichtung

  1. Library installieren

    Im Terminal: pip install garminconnect

  2. Credentials in ~/.zshrc eintragen

    Einmalig, damit du nie wieder Passwort eingeben musst.

  3. ~/.zshrc öffnen und diese zwei Zeilen ans Ende einfügen

    Dann source ~/.zshrc im Terminal ausführen.

~/.zshrc
export GARMIN_EMAIL="deine@email.de"
export GARMIN_PASSWORD="deinPasswort"

Verwendung

Terminal — im Sport/ Ordner ausführen
# Letzte 7 Tage (Standard)
python3 garmin_sync.py

# Letzte 30 Tage
python3 garmin_sync.py --days 30

# Alles bisher noch nicht Gesynctes
python3 garmin_sync.py --all

Was wird wohin sortiert?

Garmin AktivitätstypZielordnerDateiformat
running, treadmill_running, indoor_runningimports/laufen/.fit
strength_training, fitness_equipment, otherimports/gym/.fit
swimming, lap_swimming, open_water_swimmingimports/sonstiges/.fit
elliptical, armwrestling, alles andereimports/sonstiges/.fit

Das Script merkt sich bereits heruntergeladene Aktivitäten in .garmin_sync_state.json — kein doppelter Download bei mehrfachem Ausführen. Bei Garmin-Fehler 429 (Rate Limit): 15–30 Minuten warten und erneut versuchen.

Gym-Daten importieren

Gym-Einheiten werden als Samsung-Notizen-Export (.txt) in imports/gym/ abgelegt. Claude liest diese Dateien und trägt Gewichte, Sätze und Wiederholungen in fortschritt/gym_progression.md ein.

Workflow

  1. Nach jeder Gym-Einheit

    Notiz aus Samsung Notizen exportieren und in imports/gym/ ablegen.

  2. Claude anweisen

    Im Chat: "Analysiere meine neuen Gym-Einheiten und aktualisiere die Progression."

  3. Claude trägt automatisch ein

    Gewichte und Progression landen in fortschritt/gym_progression.md.

Hinweis zu Garmin Gym-Daten: FIT-Dateien von Garmin enthalten für "Sonstige"-Aktivitäten keine Übungsdaten (nur HR + Kalorien). Die echten Gym-Details kommen aus deinen Samsung-Notizen.

Kalenderintegration

Claude hat Zugriff auf Google Calendar (Privat, Gym, Arbeit, Uni) und handelt nach diesen Regeln:

🟢

Trainingseinheiten

Gym-Kalender, Farbe Basil/grün für Gym, Peacock/blau für Laufen, Lavendel für Schwimmen.

🔔

Erinnerungen & Aufgaben

Gewicht tracken, Fortschritt eintragen — landen im Privat-Kalender mit Popup-Erinnerung.

🚫

Busy-Zeiten

Arbeit Mo–Fr 08:00–16:30. Gym frühestens ~17:00 (20 min Anfahrt). Claude plant automatisch drum herum.

Wöchentliche Routine

  1. Montag morgens — Gewicht eintragen

    Nüchtern wiegen → Claude im Chat sagen → wird eingetragen.

  2. Nach Trainingseinheiten — Garmin syncen

    python3 garmin_sync.py im Terminal ausführen.

  3. Gym-Notiz ablegen

    Samsung-Notiz aus der App exportieren → imports/gym/ ablegen.

  4. Claude anweisen zu aktualisieren

    "Analysiere meine neuen Daten und aktualisiere Fortschritt und Plan."

  5. Wochenplan für die nächsten Tage anfordern

    Claude prüft den Kalender und erstellt einen aktualisierten Plan inkl. Kalendereinträgen.
